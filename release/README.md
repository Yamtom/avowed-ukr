# Avowed — українська локалізація (патч IoStore)

Патч **`Alabama-WinGDK_Ukr_P`** підміняє текстові таблиці гри (`Text_plpl.uasset` для BaseGame і DLC D11) українським текстом.
Оригінальні файли гри не змінюються: видалення трьох файлів патча повністю повертає гру до початкового стану.

Український текст відображається, коли в налаштуваннях гри обрано **польську мову (Polski)** — патч використовує її слот.

## Склад теки
| Файл | Призначення |
|---|---|
| `Alabama-WinGDK_Ukr_P.pak / .utoc / .ucas` | основний патч (всі три файли потрібні) |
| `install.bat`, `uninstall.bat` | установлення / видалення |
| `fonts\` | **необов'язковий** патч шрифтів (кириличні гліфи для EspinosaNova і Celestia Antiqua) |
| `ru-slot\` | **необов'язкова** альтернатива: той самий текст у російському слоті (`ruru`), не перевірено в грі |
| `QA_REPORT.md` | звіт перевірки якості та відновлення NodeLinks |
| `INGAME_CHECKLIST.md` | що перевірити вручну в грі |
| `SHA256SUMS.txt` | контрольні суми двійкових файлів |

## Встановлення
1. Закрийте гру.
2. Запустіть `install.bat` (шлях за замовчуванням — `M:\XboxGames\Avowed\Content\Alabama\Content\Paks`).
   Інша тека: `install.bat "D:\...\Alabama\Content\Paks"`. Разом зі шрифтами: `install.bat /fonts`.
   Скрипт перевіряє, що в теці є оригінальний `Alabama-WinGDK.pak`, і відмовляється працювати при запущеній грі.
3. У грі оберіть мову **Polski**.

Ручне встановлення — скопіюйте три файли `Alabama-WinGDK_Ukr_P.*` у теку `…\Alabama\Content\Paks\`.
Підтека `~mods` не потрібна: рушій монтує всі контейнери теки `Paks`, суфікс `_P` дає патчу пріоритет над базовим контейнером.
Файл `.pak` (347 байт) обов'язковий — без нього контейнер `.utoc/.ucas` не змонтується. Правок `DefaultGame.ini` не потрібно:
нової мови не додається, використовується наявний слот.

## Видалення
`uninstall.bat` (з `/fonts` — разом із патчем шрифтів) або вручну видаліть `Alabama-WinGDK_Ukr_P.*`.

## Після оновлення гри
Патч прив'язаний до ідентифікаторів чанків оригінального контейнера гри (редакція від 26.03.2026). Після оновлення гри
видаліть патч, запустіть гру, а потім перебудуйте його з репозиторію:

```
python tools/build_iostore_patch.py selftest
python tools/build_nodelinks_uk.py build
python tools/build_iostore_patch.py build --out-dir release --strict-links --install
```

`selftest` порівнює утиліту з оригінальним контейнером; якщо він падає, патч не можна встановлювати.

## Мовний слот і множина
Слот `plpl` уживає польські правила множини для `|plural(one=…, few=…, many=…)`: форма `one` лише для 1. В українській
`one` також для 21, 31, 101… Це стосується 7 рядків (напр. «очко/очки/очок особливостей» — для 21 з'явиться «очок»).
Варіант `ru-slot` має ті самі правила множини, що й українська, але в грі не перевірений.

## Шрифти
Оригінальні EspinosaNova і Celestia Antiqua не містять кирилиці. Патч шрифтів додає 98 гліфів (кирилиця U+0400–045F та Ґґ), узятих
з DanteeText; DanteeText, SegoeUI, Roboto та інші шрифти кирилицю мали. Патч шрифтів ставте окремо (`install.bat /fonts`),
вигляд у грі автоматично не перевірено. Знак «№» і U+02BC шрифти не мають — у тексті їх не вжито (апостроф — U+0027).

## Відомі обмеження
- Гру в ході цієї роботи **не запускали**: усі висновки — з автоматичних перевірок (`QA_REPORT.md`). Користуйтеся `INGAME_CHECKLIST.md`.
- 303 рядки інтерфейсу довші за 140% англійського оригіналу — можливе обрізання в кнопках і підказках.
- NodeLinks (підсвічені терміни лору) відновлено для ~98,5% оригінальних посилань; решту, що не вдалося відновити без
  припущень, перелічено в `logs/nodelinks_miss.tsv` — там текст просто без підсвічення.
